# UaiMoney 💰

Sistema de controle financeiro focado na agilidade e no uso diário.

## O Projeto
O UaiMoney nasceu com a proposta de ser um Produto Mínimo Viável (MVP) rápido e funcional. O objetivo é evitar a complexidade extrema, permitindo o registro de entradas e saídas de forma direta e sem atrito.

## Tecnologias Utilizadas
* Front-end: HTML, CSS (Bootstrap) e JavaScript.
* Back-end: PHP.
* Banco de Dados: SQLite (Arquivo único local).
* Gráficos: Chart.js.

## Estrutura Inicial
* Menu inferior fixo para navegação rápida no smartphone.
* Visão Geral: Dashboard com saldo e divulgação progressiva de detalhes.
* + Receita: Interface verde dedicada ao registro de entradas.
* - Despesa: Interface vermelha dedicada ao registro de saídas.
